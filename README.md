# Lagos HealthMap: Spatial Analysis of Medical Infrastructure

With a rapidly growing population, understanding the precise distribution of healthcare facilities across **Lagos State** is a critical geographic challenge. This project aims to raw, crowdsourced OpenStreetMap (OSM) data into a structured, visually actionable GIS database of hospitals, clinics, and pharmacies in a way that the everyday citizen can easliy interpret.

---

## Why Health Care?

>Lagos State's high migration rate places continuous pressure on local healthcare systems. This project utilizes spatial data analysis to map the exact distribution of medical facilities across the state, identifying areas of high facility concentration and critical low-density zones.

## The projected solution.
This end-to-end methodology bridges crowdsourced spatial data with official government statistics to create a robust geographic database of Lagos State’s healthcare capacity, delivering clear, static maps that can be easily interpreted by the end user.
